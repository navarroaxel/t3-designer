# Shared components
React 19 + Vite + TypeScript + vanilla CSS. No UI component library and no shared exported UI primitives exist yet. HTML buttons, inputs, badges, fieldsets and tabs are inline in `apps/web/src/App.tsx`; its full implementation is in `layouts.md` to avoid duplication. `ApartmentScene` and architectural components are page-specific 3D components, not UI primitives.
